# Security

Do not include real prompts, credentials, browser profile data, or private backups in bug reports. Use fabricated examples to reproduce issues.

Before distribution, provide a private security reporting contact here and in the store listing. No public security contact has been configured for this private development project.

The main boundaries are untrusted import files, extension messages, stored documents, clipboard writes, and plain-text rendering. Report data loss, validation bypasses, unexpected network requests, or unintended website access with the extension version and reproduction steps.
